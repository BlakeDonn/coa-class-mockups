The same spec, both systems

Godblade, Boss context, real values. Left is the 1–5 pip system the site already speaks. Right is the constellation shape built from the identical six numbers. Every pip row carries its tooltip: the axis, the value, and the researched why.

What each claims. Pips are numbers you can read — exact, familiar, tooltipped. The shape is a silhouette you can recognize — same-shaped specs play alike, before any reading. The question of this round: which does the map's job, or do they need each other?

1 · The unit — how one spec renders

One class's specs, shown in all three directions at once so the comparison is direct. Change the class and context; every direction re-renders from the same values. Tap any unit for the full profile.

U1 · The pip ladder

The system you know, compacted: six axes, five diamonds each, tooltips with the researched why. Gains: exact and instantly familiar; the ruled class-page tooltip treatment carries over whole. Costs: six rows must be read one by one — nothing about the spec arrives at a glance.

U2 · The shape

The same six values as one silhouette. Gains: the spec's character arrives before any reading; similar shapes play alike across the whole page. Costs: values are approximate until tapped; the spoke order must be learned once.

U3 · Shape + ladder, fused

The shape gives the gestalt, the pips give the numbers, one unit. Gains: nothing is lost — recognize first, read second. Costs: the widest unit; at 70 specs the wall gets heavy.

2 · The wall — all 70 at once

The map's actual job: every spec on one surface. Flip between the three treatments; each renders the full roster in the context picked above, grouped by class, roster order. No sort controls anywhere — ordering by an axis would read as ranking.

Values carry Data · Players · Inference tiers and are relative among researched CoA specs. Axes are demand, never quality. An unresearched value renders hollow, never zero.
